# Contributing

Thanks for your interest in contributing!

## How to contribute

1. Fork the repo
2. Create a branch: `git checkout -b feat/my-change`
3. Make changes with tests (when applicable)
4. Update documentation for any user-visible behavior
5. Open a Pull Request

## Code style

> Replace with project-specific style rules.

- Format: `prettier` / `black` / `eslint --fix` (once configured)
- Lint: `npm run lint` / `ruff` / `flake8`
