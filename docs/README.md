This repository currently contains a minimal placeholder README. The recommended documentation structure is below.

- `README.md` (project landing page)

  - `docs/development.md` (dev setup)
  - `docs/contributing.md` (contribution guidelines)
  - `docs/api.md` (API reference / endpoints)
